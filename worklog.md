Work Log:
- Root-caused the scroll fight: the old follow logic used distance hysteresis (unpin only past 160px away), so a small upward scroll still counted as "pinned" and the MutationObserver kept snapping scrollTop to the bottom on every streamed mutation — the page fought anyone scrolling up. Also the submit/status effects used smooth scrollTo which chased a moving target (the "lag when scrolling down").
- Rewrote the follow system in /r/[id]/page.tsx: pinnedRef (intent) + lastTopRef (direction) + jumpingRef (programmatic-flight tracker). ANY upward delta < -3px releases the pin instantly; away <= 24 re-pins; smooth flights are bounded (900ms safety) and exempt from the observer (no mid-flight fights); content-growth snap is instant (chat-app standard); the observer no longer calls setState (the induced scroll event updates the pill — fewer renders).
- Jump button redesigned: glass pill with label + pplx-dot live indicator ("Live · jump to latest" while a run is active), positioned absolute above the composer inside the dock's relative wrapper — centered on the chat column at every breakpoint (the old fixed left-1/2 was viewport-centered, wrong at xl where the rail shifts the column 164px left). Show/hide hysteresis (>=140 show, <=90 hide) kills threshold flicker.
